# Codex真实建议：云端任务队列

网页把数据快照发送到原Supabase项目中的独立任务队列，运行助手的电脑调用Codex，再将建议送回弹板。网页和负责计算的电脑不必相同。

## 已具备

- 复用电脑中已经可用的 Codex 模型配置，无需在网页填写模型密钥。
- 云端任务表开启RLS并禁止匿名用户直接读写，只允许持对应配对凭证的受限函数访问。
- 提交与领取/回传使用不同的随机凭证，数据库只保存凭证哈希。每小时20次、至少间隔10秒、同一时间一条活动任务。
- 本机诊断服务只监听127.0.0.1:4318，不需要开放公网端口。
- 网页只发送月份、计划起点、回报比、占比、调量目标，不发送数据库密钥或整份存档。
- 模型决定产品及两个岗位组的分配；程序校验整数、下限和两个目标的准确合计。
- 分配先均衡、再按表现适度拉开差距。普通同向且总量足以覆盖产品时，产品总调整量采用平均量约50%至150%的宽松防偏斜范围（取整）；模型优先在更接近平均值的位置分配。该范围不是固定相差5条，不限制单个弱岗位为0。稀疏增量、相反岗位目标或减量容量不足时，不套用不可行的统一范围。
- 数量或均衡校验未通过时，会在原有3分钟时限内自动要求模型重算一次；不会用本地公式偷偷改写模型结果。
- 校验成功后进入原有弹板，仍需用户点击应用。模型失败不会偷偷切回规则结果并允许应用。
- 取消或生成过程中原数据变动，不应用过时结果。原有手动调整和撤销路径保留。
- 配对码仅是本机助手调用凭证，不是 Codex 登录凭证。不要分享配对码。

## 启动与连接

1. 在 PowerShell 运行此目录的 `启动本机助手.ps1`，保持运行。
2. 打开看板，进入需求量方案 → AI建议 → 连接Codex AI。
3. 云端配对码位于项目 `.local-backups/codex-bridge/云端AI配对码.txt`，复制到连接弹板。
4. 其他电脑首次使用也需填写同一配对码；无需安装Codex或配置模型密钥。
5. 已连接的浏览器再次点击 AI建议，将请求真实模型。连接信息保存在该浏览器中，业务数据仍在Supabase中。
6. 保持负责计算的电脑开机、联网，助手进程不能退出。电脑休眠、关机或助手关闭时，网页会提示未连接。
7. AI弹板中的“全屏”将弹板铺满页面；按钮或Esc可退出全屏，保留当前草稿。普通模式再按Esc才取消弹板。

计算可能消耗现有模型服务额度，当前实际使用的是电脑已有的模型提供方配置，不代表已验证 ChatGPT 订阅计费方式。启动时禁用已配置的MCP连接器和插件，限制只读环境，不向网页暴露模型登录信息。

## 数据与安全

迁移文件：`supabase-ai-queue.sql`。只增加 `demand_ai_workers`、`demand_ai_jobs` 和六个受限RPC函数，不修改业务数据。安装位置：Supabase → SQL Editor。已在当前项目执行。

任务超过5分钟可被标记过期，超过24小时不再通过配对接口返回结果。当前不自动删除任务记录，管理员可在控制台审计。所有数据快照和模型输出仅用于建议；只有用户确认应用才调用原有业务保存功能。

本地 `.local-backups/codex-bridge/queue-config.json` 含助手凭证，不能上传GitHub或分享。配对码泄露时需在控制台停用该worker并更换配对信息。模型失败、整数/目标校验失败、数据变更均阻止应用。

诊断用的本机直连仍保留，但正式网页使用云端队列。不要开放4318端口到公网。未验证操作系统开机自启动；本版需主动运行启动脚本。

上线前还需在正式HTTPS页面验证浏览器本机网络限制，或完成云端队列方案；当前 Pages 仍使用原有规则计算，界面标识不能冒充真实AI。
